# T13. Звук / вібрація та індикація нових замовлень для персоналу (BACKLOG Q6, частина)

| Поле | Значення |
|------|----------|
| Пріоритет | P3 (хвиля 3) |
| Розмір | S |
| Статус | Todo |

## Проблема
Персонал не помічає нове замовлення, якщо вкладка не в фокусі.

## Обсяг
- Короткий звуковий сигнал і `navigator.vibrate` при SSE-події про нове замовлення (не при зміні статусу).
- Перемикач «Звук» у Header (зберігається в `localStorage`, обгорнуто try/catch); вимкнено до першої взаємодії (autoplay-політика браузерів).
- Лічильник нових замовлень у `document.title`, скидається при поверненні у вкладку.
- `aria-live="polite"` оголошення «Нове замовлення #…» для скрінрідерів.

- [ ] Юніт-тест хука на подію SSE; звук не грає при вимкненому перемикачі.
- [ ] Без регресій у `Header.test.tsx` та тестах a11y.
