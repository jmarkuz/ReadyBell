## Мета
Автоматично перевіряти головний сценарій у реальному браузері: персонал входить → створює замовлення → QR-посилання →
клієнт бачить статус → персонал ставить READY → клієнт бачить READY. `scripts/smoke.sh` покриває лише API.

## Обсяг
- `dashboard-ui/e2e/` + `playwright.config.ts`, запуск проти `docker-compose` (Postgres + Redis + API з UI) і dev-seed.
- Сценарії: логін, New order + QR, `/track/:id` оновлюється через SSE, Incoming Orders пагінація для 25 замовлень (із `test-orders-50.json`), темна тема.
- Окремий job у `.github/workflows/ci.yml` (артефакти: trace, відео при падінні).

## Критерії приймання
- [ ] Зелений прогін у CI < 5 хв; нестабільність < 1 % за 20 прогонів.
- [ ] Документація запуску в `docs/DEVELOPMENT.md`.
